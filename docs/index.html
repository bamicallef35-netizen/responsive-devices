keyring — senses you can carry

all eight plates on one printable sheet.

Eight pocket devices, each adding one channel of the world to what its wearer can perceive: the magnetic field as touch, the ultraviolet a bee sees, the infrared a pit viper feels, ultrasound brought down into hearing, the sky's polarisation, nearby radio, vibration below hearing, the flicker of lamps. Every one is a named set of parts for roughly £3 to £15, with firmware short enough to read in a minute and syntax-checked in the repository. The plates below are drawings of proposals; none of these is a product.

  • lodestone — the magnetic field, as touch. Hall sensor or magnetometer / vibration motor / ~£7–15

  • ultraviolet — what a bee sees. UV photodiode / five-LED bar / ~£8–15 / not a UV index

  • heat — what a pit viper feels. MLX90614 thermopile / pitch or a small display / ~£15–20

  • bat — ultrasound, brought down into hearing. ultrasonic MEMS mic / divide-by-16 to an earphone / ~£12–18

  • polar — the sky's compass. two discs of polarising film, no electronics / ~£3

  • radio — nearby transmission. diode detector / LED / ~£5–8 / does not find hidden cameras

  • tremor — vibration below hearing. piezo disc / LED or vibration / ~£5–7

  • lumen — hearing the lights. photodiode / earphone / ~£4

the six room-scale proposals

HEARTH, REFUGE, CANDID, SPECULATRIX II, PARLEY and MUSICOLOUR II are in the repository, each with the same split between what named parts deliver today and what remains speculative, and an ethics note. Each plate below draws the loop the device closes and states its scenario — programme, area, cost, parts, premise — in the format R&Sie(n) used for every project.

  • HEARTH — an offline companion node. ~£130–160 / the software half runs in offline-edge-node

  • REFUGE — a responsive rest-and-attention environment. ~£150–300 / not a medical device

  • CANDID — a consent-first biometric-aware object. ~£20–40 / on-device, ephemeral, no identity

  • SPECULATRIX II — a desk creature that habituates. ~£25–45 / builds on grey-walter-tortoise

  • PARLEY — a room that negotiates its own lighting. ~£60–150 / authority sized to need

  • MUSICOLOUR II — a sound-to-light instrument that habituates. ~£30–60 / after Pask and McKinnon-Wood
